# E-Commerce Website Testing Portfolio

## Project Overview
A software quality assurance portfolio demonstrating manual testing and browser automation on a sample e-commerce application.

## Objectives
- Test login and validation workflows.
- Verify product listing and sorting.
- Test shopping cart functionality.
- Validate checkout and order confirmation.
- Document defects and test execution results.
- Automate selected scenarios using Selenium WebDriver, Java and TestNG.

## Technology Stack
- Manual Testing
- Java
- Selenium WebDriver
- TestNG
- Maven
- Git and GitHub

## Project Structure
- `src/test/java/com/portfolio/qa/` — Automation test scripts
- `test-data/` — Manual test cases and test data
- `bug-reports/` — Bug report templates and verified defects
- `target/surefire-reports/` — Generated automation results

## How to Run
1. Install JDK 21, Maven and Google Chrome.
2. Clone the repository.
3. Open a terminal in the project directory.
4. Run `mvn clean test`.
5. Review the generated reports under `target/surefire-reports/`.

## Test Coverage
Login, negative login, product selection, cart operations and checkout.

## Results
Record the actual number of passed, failed and skipped tests after execution. Do not publish unverified results.

## Learning Outcomes
Functional testing, test design, assertions, defect reporting, browser automation and version control.
